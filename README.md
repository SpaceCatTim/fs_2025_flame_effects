# fs_2025_flame_effects
Code repo for the Burning Flipside 2025 effigy flame effects

This repo contains multiple projects - each is a node on a LoRa mesh network. 
The target Arduino device is a Pro Micro (3.3V preferred). The LoRa radio modules used are RYLR998 (3.3v).

Link to buy: https://www.amazon.com/REYAX-RYLR998-Interface-Antenna-Transceiver/dp/B099RM1XMG/
Datasheet: https://reyax.com/upload/products_download/download_file/RYLR998_EN.pdf

Other hardware / modules used:

Mini void - microphone - https://www.amazon.com/dp/B07J6N734S?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_1
Heartrate sensor - AD623 instrumentation amplifier - https://www.amazon.com/Amplifier-Adjustable-Instrumentation-Single-ended-Differential/dp/B09Q2RQ6FL/
